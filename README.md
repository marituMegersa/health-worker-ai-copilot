# Health Worker AI Copilot 🚀

WHO SMART Guidelines & Ethiopian MoH Decision Support Platform

## 📁 Monorepo Structure

```text
health-worker-ai-copilot/
├── apps/
│   ├── api/                     # Python 3.12 FastAPI Backend
│   └── web/                     # React 18 TypeScript Frontend
├── docker-compose.yml           # Full Stack Container Setup
└── README.md
```

## 🚀 Quick Start

### 1. Run Python FastAPI Backend (`apps/api`)
```bash
cd apps/api
pip install -r requirements.txt
python main.py
```

### 2. Run React Frontend (`apps/web`)
```bash
cd apps/web
npm install
npm run dev
```
